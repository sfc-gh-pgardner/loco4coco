connection called `BOOTH` was a design error. Cortex Code's connection picker
holds its own runtime selection, so the operator's original OAuth connection

connection on the same account for the `ALTER USER`, so registration need not
cost a prompt.

## Watch out

- `str.replace` on `game/server.py` fails silently when the real line carries a
  `# noqa: BLE001` comment. Cost a wasted smoke-test run. Use the `edit` tool or
  grep to confirm the patch landed.
- Server restart: `pkill -f 'server\.py'` works, `pkill -f 'python3 server.py'`
  does not.
- Heredocs into files mangle paths in this shell; use the `write` tool.
